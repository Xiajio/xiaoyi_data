# 演示操作说明

所有角色、患者、字段和任务均为虚构。一次完整演示约 5–8 分钟。

## 1. 批次接入与处理

选择“数据管理员”视角，在数据接入页查看四类资料并模拟接入。进入数据处理，查看字段模板，展开处理计划并确认模拟执行。进度变化后可在执行记录查看结果。

可以主动选择模拟失败，再从失败记录重试。每次重试有新的运行记录，已做的人工核验不会被覆盖。运行中刷新页面会将任务标记为中断，不会悄悄继续。

## 2. 对照证据核验

选择“临床审核员”，进入核验工作台：

- 普通字段可以确认与原文一致。
- 报告日期的原始候选把取材日期当作报告日期。对照证据，将报告日期修正为 `2026-03-05`，填写核验依据。
- 治疗事件的原文是计划实施。将状态修正为“计划”，保留原候选及修订说明。
- 随访资料没有记录相关结局，选择“保留未记录”并说明已核查范围。缺失不等于阴性。
- “待补资料”仍然是未解决状态，不能发布。关键冲突不能用直接确认跳过。

病例资料库能查看同一对象的资料关系。P-DEMO-002 保留隐私检查未通过的演示状态，用于展示发布阻断，不需要把全部 6 个字段都改成可发布。

## 3. 冻结和发布

进入数据集与发布，选择“仅选择可发布字段”，检查各字段的阻断原因，再冻结候选版本。切换“项目负责人”视角审批。

批准后可选择相应版本查看和导出合成 JSON。后续核验改动会使相关待审批快照失效；已经批准的旧版本继续保留。新内容应另行冻结与审批，导出时明确选择快照。

## 4. 进度与重置

关闭、重开或刷新页面，会恢复同一浏览器和同一演示会话的进度。右上角“重置演示”会恢复该会话的初始数据。缓存不可用时仍可体验，但页面会明确提示无法保存；缓存损坏时需显式重置。

角色是演示视角，不是服务端权限。运行与审计页展示演示操作记录；性能和独立质量验证没有真实测量，保持“未测量”。

## 5. 宿主演示

打开 `host.html`，在示例宿主中打开工具，尝试定位字段、主题切换、关闭和重开，验证已保存进度。切换演示会话后，应看到独立的数据、角色和版本记录。嵌入时的导出结果发给宿主，由宿主示例提供下载。
