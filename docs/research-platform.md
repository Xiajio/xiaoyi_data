## 原调查问题的修复

| 原问题 | 结果 |
|---|---|
| 旧版本冻结混入新元数据 | 配对和快照读取选定版本的元数据与证据；已批准内容不随最新源变化 |
| 不兼容模态/许可仍能发布 | 统一硬约束检查；未知不算满足；确认、冻结、批准均阻断不匹配 |
| 失败项后水位推进导致漏采 | 单项结果持久化，有失败不推进越过该批的成功水位，重试可去重 |
| 中断任务无运行记录 | 运行先落盘、短事务更新；中断/失败保留记录 |
| 字节数作为行数 | HF 字节与行数分离，缺少行数时保持未知 |
| SQLite 无时区时间相减报错 | 时间统一处理 UTC，兼容数据库返回的无时区值 |
| 全局向量截断导致筛选后排序错误 | 先结构筛选，再在筛选结果中计算排序 |

新增回归还覆盖：机器越权、请求体伪造角色、Bearer 注销、模型错误结构与无效证据、超预算、恢复去重、偏好不绕过硬约束、部分下载重试的配额与批准归属、首次并发导出、历史证据显式恢复、非对象 JSONL 预览、派生完整研究包链路。

## 内容与交付的实际范围

- 文本/表格：最多首 10,000 行、普通文本类文件最多 32 MiB 的有界检查；CSV/TSV/JSONL/JSON/TXT/Parquet 结构、缺失、重复及已检查行的相同记录提示。Parquet 按批读取，行覆盖明确记录。
- 图像：格式、尺寸、模式、损坏检查与已取得图像缩略图。预览设置像素上限。
- 三维：OBJ 基础顶点/面计数；PLY 文件头声明；glTF/GLB JSON 结构、节点、mesh 与外部资源数量。复杂几何完整性、修复和转换不在此版本；不请求外部资源。
- 去重派生：不改原始文件，保存输入资产 ID/哈希、父版本、算法版本和参数；派生仍需作为新版本经过配对与发布核验。
- 研究包：版本元数据、文件清单/哈希、来源/许可、证据、schema/split 整理、测量报告、核验与派生记录，包内固定 `load_data.py`；缺资产的旧快照只导出原目录 JSON。
- Croissant：文件描述与实测 CSV/TSV/Parquet 列结构，使用明确的 JSON-LD 词汇映射；未知语义类型、主键和切分不补造。CSV/TSV 按固定加载器的字符串类型表示。规范依据为 [Croissant 1.1](https://docs.mlcommons.org/croissant/docs/croissant-spec-1.1.html)，本地验证检查引用和包内文件定位，未宣称通过所有第三方 Croissant 消费端兼容验证。
- “目录信息完整度”只描述目录证据完整情况，不表示真实数据内容质量或科研有效性。抽样报告保留样本量、截断和覆盖范围。

## 首页数据中台可视化增量

工作概览使用 `GET /api/overview/dashboard?days=14|30` 的真实聚合统计：目录规模、版本与证据、已登记文件、整理核验状态、近期入库、模态与许可分布、采集历史及下次同步计划。每 15 秒更新，刷新失败会保留并注明上次结果；点击模态或许可进入对应目录筛选，可展开图表数据表、用键盘选择趋势日期。

口径约定：

- 目录、版本、证据、整理和资产限定当前有效数据集；版本包含历史与派生版本。已批准快照与已生成研究包保留团队历史交付计数。
- 14/30 天切换仅影响趋势。按上海自然日统计本地首次入库数据集及新增版本，今天尚未结束，不使用来源更新时间代替入库时间。
- 每个数据集的模态去重后计数，多模态可出现在多个类别；空模态单列。许可分类未知可能是信息缺失或尚未归类，不能当作已获使用许可。
- 文件体积为登记文件的逻辑字节数，可能包含复用文件，不表示实际磁盘占用。历史采集失败/部分完成不等同于当前未解决故障；后续重试可能已经成功。
- 流程节点使用各自记录单位，箭头只表示工作顺序；整理核验入口进入工作台，模态与许可提供精确分类筛选。
