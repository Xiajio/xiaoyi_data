## 已实际覆盖的场景

1. 接入合成批次、确认处理计划、模拟执行、失败重试、刷新中断；人工核验结果不被覆盖。
2. 原文证据与问题表格定位；报告日期修正为 2026-03-05、治疗状态修正为“计划”、随访保留“未记录”；原始候选与依据保留。
3. 关键冲突、未核验、待补资料、隐私检查阻断；合格字段冻结、审批与实际 JSON 下载。
4. 待审批版本失效、已批准版本不随修订变化；刷新后恢复、显式重置、损坏缓存保护和不可用存储的内存模式。
5. 宿主主题、导航、定位字段、关闭与重开、A→B→A 会话隔离、实际导出事件与下载。
6. 错误 origin、非父窗口来源、旧实例、非法参数、旧序号消息拒绝。
7. 实际 iframe 内容宽度为 1600、1050、520 像素时完成核验、冻结、审批、导出；独立模式七页在三种宽度无整页横向溢出。
8. 运行中切换会话或重置后，推进浏览器时钟不会让旧任务写回新状态。
9. 无根路径回退的 `/demo/` 静态子目录部署，工具和宿主示例可用；无 404、页面异常或控制台错误。
10. 浅深主题截图人工查看，键盘焦点检查；运行时资源来自部署站点，无医院、模型、字体 CDN 或分析服务请求。
