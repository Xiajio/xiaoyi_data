## 数据可视化改进

构建页使用固定清单绘制同一数量刻度的处理结果、排除原因及实际切分比例，支持版本状态筛选、标签切分选择和后续测量分页。未知值与零分母不补成零；切分总量不一致时隐藏占比。原始清单按需展开，输入列表先展示前 20 个资产，保留完整来源与哈希。

实验对照在服务端核对协议成功后显示固定 0–100% 准确率、可选基线、百分点差值、预测覆盖与错误数量；失败或选择变更立即清除旧图。队列显示统一刻度的待执行/延后/运行数量、心跳和过期租约，并明确失败率分母；不从资产大小推造磁盘总量或利用率。零总结任务不显示 100% 完成率。

本次未引入图表依赖。新增数据口径测试覆盖缺失值、错误分母、切分对账、API 对照结构及陈旧快照；浏览器回归覆盖显式基线切换与第 51 条测量加载。真实 PG 可视化夹具另行执行四组固定 CPU 训练，所有新增输入均经独立人工批准，原构建 1–4 保留。该合成对照只用于交互验收，不表示实际科研收益。

## 操作与兼容边界

版本化任务、审核和Job接口见 [接口约定](task-jobs-api.md)。

- 启动与环境变量：[部署手册](deployment.md)。历史迁移与主键/审核/checkpoint 处理：[迁移手册](history-migration.md)。停写备份和恢复：[恢复手册](backup-recovery.md)。
- HTTP、CLI 和 MCP 共用提交函数；派生、画像、构建、挖掘、训练包与研究包打包返回后台任务。研究包 GET 只返回已完成包，尚未生成返回 409；客户端提交任务后查询状态。
- 当前行样本可扩到百万。每配方显式源资产上限 10,000；百万个独立图像文件需要后续的流式资产清单选择接口。大视频/音频/三维/代码仍保留目录与资产能力。
- 外部实验首版实现分类评估，未声称支持检测、分割和回归评估。近重复使用有界 CPU 指纹召回，不是语义真值。
- 旧任务在停旧 worker 后幂等映射到 Job。SQLite checkpoint 完整归档，历史失败任务重新发起为新 run，双向关联旧记录且不继承下载/发布批准。
- 分阶段开放：先在隔离恢复副本验收 M0，再核对 M1 历史审核与约束；停旧 worker 后开放 M2；试点批准资产验证 M3，再开放 M4/M5。首轮保留所有旧结构与映射；回退恢复到新库与新资产位置，不删除原库，不直接覆盖上线后新增记录。
